Project Title- Number Guessing Game using Python
Overview of the Project- This is a simple Python based number guessing game in which computer generates a random number and the player has to guess it.
Features- Generates a random number automatically, gives hints based on the user's guess and counts the number of attempts taken. It displays a success message when the correct number is guessed.
Tools used- language: Python, Module: Random, IDE: VS Code, platform: GitHub
Steps to run the Project- Install Python and download or clone the project from GitHub. Open the project folder and open the terminal and run the project. Enter your guesses when prompted.
Instructions for Testing- Run the program using the command =. Enter a number as your guesses. Check whether the program displays "go higher" or "go lower" and continue guessing until the correct number is found. Verify that the number of attempts is displayed correctly.
