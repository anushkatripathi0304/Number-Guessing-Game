Problem statement- Designed to provide a simple and interactive gaming experience where player has to guess number using the hints.
Scope of the Project- Develop a simple number guessing game using python and allow users to enter their guesses. Provide hints to get closer to the desired numberand track the number of attempts made by the player
Target Users- Beginners learining Python programming. Students interested in basic coding projects. People who enjoy guessing games. Anyone looking for fun interactive games 
High level features- Random number generation, User input, Hints and Feedbacks, Attempt counter, Winning message
